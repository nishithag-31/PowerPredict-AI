# PowerPredict AI

## Intelligent Energy Demand Forecasting for Smart Cities

### Project Description

PowerPredict AI is an end-to-end MLOps-based energy demand forecasting system designed for smart cities.

The project predicts future electricity demand using Machine Learning while implementing modern MLOps practices such as:

- Energy Demand Forecasting
- Data Drift Detection
- Automated Model Retraining
- Explainable AI (SHAP)
- Model Monitoring Dashboard
- MLflow Experiment Tracking
- AI-Based Grid Decision Support

### Tech Stack

- Python
- Scikit-learn
- Pandas
- MLflow
- SHAP
- Evidently AI
- Streamlit
- Prefect
- Docker
